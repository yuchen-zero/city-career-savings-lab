# 2027 届上海临港电气应届生深化研究

研究范围为上海市浦东新区临港新片区，重点按滴水湖与南汇新城核心区操作；数据截止日为 2026-10-26。

## 核心口径

- 核心区取得 6 条 2027 届本科相邻岗位，来自 3 家企业；中芯国际占 4 条，即 66.7%。
- 公开薪资、明确双休、明确不出差均为 0 条；6 条均未同时确认双休和不出差。
- 8,000、10,000、12,000、15,000 元是现金压力测试，不是观测到的应届工资。
- 默认测算为税前 10,000 元、12 薪、合租中介押一付三、月租 1,300 元：月均到手 8,197.50 元，纯现金净结余 4,153.68 元，含个人公积金 4,853.68 元，首月最低现金 8,360.90 元。
- 7 条排除市场锚点的年化月薪范围是 8,125 至 20,000 元，中位数 16,291.67 元；其中包含硕士、经验岗和售后岗，不能当作本科应届起薪。

## 目录

- `data/`：岗位、房租、生活成本、税务社保、情景、证据台账和分析 payload。
- `scripts/`：数据构建、报告/Excel 生成及自动化审计脚本。
- `outputs/`：正式 Word、Excel、HTML 和汇总 CSV。
- `config.json`、`research_brief.md`：项目参数与研究边界。

数据版本为 `2027EE-LG-20261026-v1`，`data/build_manifest.json` 保存 payload SHA-256。完整浏览器原始捕获没有进入仓库，来源 URL、采集日、证据等级和原始文件相对路径保留在 `data/evidence.csv`。

BOSS 直聘最终显示登录页，本研究没有绕过验证码，也没有保存 Cookie。该覆盖缺口已在报告和 HTML 中披露。
