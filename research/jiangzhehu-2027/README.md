# 2027 届江浙沪电气应届生调研

本目录保存面向 2027 届电气工程及其自动化本科应届生的江浙沪城市比较数据与交付物。`data.json` 覆盖 25 个城市，包含招聘薪资、税费、社保公积金、房租、餐饮、通勤和净结余字段。

## 目录

- `outputs/`：Word 报告、Excel 总表、交互式 HTML 和预览图。
- `data/`：成稿使用的汇总 JSON、GitHub 工具检索结果和来源摘录。
- `tools/`：报告、图表与 Excel 构建脚本，以及验证脚本。
- `questionnaire/`：需求确认问卷和生成脚本。
- `evidence/`：岗位、房租、生活成本、官方数据和筛选结果。`fullrun/combined_jobs.csv` 是全量归一化岗位样本；`pilot/`、`jdrun/`、`jdtest/` 保留抽样或详情数据。

## 读数注意

- 城市表里有实测、模型推算和范围观察等多种口径，必须结合原始字段解释。
- 招聘页转载不能当作新的岗位样本；薪资区间也不能直接当作合同固定月薪。
- 房租和餐饮不能把平台满减价、样本均值与个人实际账单混用。
- 宽口径报告适合城市初筛；如果准备签约某个岗位，应继续使用技能中的单岗位核验模式。
