# 交付物与验收

## Word 报告

默认结构如下；只有用户明确要求更短时才压缩，不能删掉方法和限制。

1. **结论先行**：最值得考虑的城市/区县、最关键取舍、排名变化条件。
2. **研究问题与用户约束**：地区、届别、专业、目标岗位、排除项、双休/出差/租房硬条件。
3. **数据与方法**：来源类型、采集时间、证据等级、样本筛选、税费和成本公式。
4. **岗位供给与广告薪资**：岗位数、企业数、集中度、中位数/四分位、薪资结构和工作条件。
5. **官方工资与外部校验**：官方指标口径、与本样本的差异、不能直接比较的原因。
6. **房租与首月现金**：整租/合租、区县差异、押付、中介/服务费、首月资金门槛。
7. **生活成本与通勤**：水电气网、餐饮、交通及其他固定支出。
8. **净结余排名与敏感性分析**：纯现金/含公积金、不同租房方式、必要区间。
9. **决策建议与下一步**：目标岗位组合、可选区县、面试核验清单、落户/补贴待核实项。
10. **限制与风险**：缺数、样本偏差、广告薪资偏差、平台限流、政策变化、行业周期。

写作要求：

- 每个主要结论同时给出数字、单位、样本和口径；不要只写“更高/更低”。
- 城市和区县排名必须注明是哪一个租房情景、哪一种薪资口径。
- 差距低于误差或样本不足时写“无法稳定区分”，不要用戏剧化语言。
- “岗位数”与“搜索返回数”分开；样本中的企业集中度用表格或文字交代。
- 把模型估算、官方规则和实测挂牌分别标记；不得把推算写成一手数据。
- 任何结论若依赖一个默认假设（12 个月租期、统一公积金比例、面积 50㎡ 等），在正文或脚注明确。

## Excel 总表

推荐至少 7 个工作表：

1. `说明与口径`：数据截止日、城市/区县、证据等级、公式版本、假设。
2. `城市净结余`：关键字段、排序、房租负担率、首月现金、证据/质量标记。
3. `岗位明细`：标准化字段、筛选结果、排除原因、来源和采集时间。
4. `岗位汇总`：按城市/区县/岗位族的样本量、薪资四分位、工作条件计数。
5. `房租与首月`：整租/合租、押付、渠道费、水电和通勤。
6. `官方工资与统计`：指标、统计期、口径、来源。
7. `证据台账`：模块、URL、原始文件、证据等级和备注。

可选新增 `敏感性分析` 与 `数据字典`。公式列按表头自动定位，不要写死列字母；在插列、排序和复制工作表后重新计算。所有派生列保留可读公式或脚本版本。

## 自包含 HTML

优先使用模板 `assets/city-savings-dashboard.template.html`，通过以下命令生成：

```text
python scripts/research_workbench.py dashboard --project <项目目录> --title "<报告标题>" --output <项目目录>/output/<报告标题>.html
```

该命令从 `data/city_model.csv` 逐行调用与 Excel、Word 相同的净结余计算函数，并把情景数据和参数化交互逻辑内嵌进单个 HTML 文件。模板中的调整项用于敏感性分析，不得改写原始数据或把假设包装成实测值。

交互页至少允许切换：

- 合租/整租和整租面积；
- 房东直租/中介/品牌公寓；
- 押金和预付月数、中介费、月/一次性服务费；
- 税前月薪覆盖值、工资年发月数、社保/公积金口径；
- 餐饮、水电气网、通勤和其他固定支出；
- 现金/含公积金口径。

页面必须同时显示：参数输入、净结余排名、首月现金、房租负担率、数据截止日、证据等级和来源说明。切换后表格与排名由同一组计算逻辑生成；不得让图表用一套口径、表格用另一套。自包含意味着断网仍能打开和交互，不依赖 CDN、外部字体或远程脚本。

## 图表选择

- 城市/区县比较：排序水平条形图，附样本数或误差/区间。
- 薪资分布：中位数和 p25/p75，不让最高薪资决定坐标尺度。
- 成本构成：堆叠条形图或明细表；类别多时优先表格。
- 首月现金：单独图或表，不与月净结余混在同一个无标注坐标轴上。
- 敏感性：小倍图、龙卷风图或情景表格；至少保留原始表格。
- 任何图都标注地区层级、情景、单位、时间和来源；“排名”要明确排序指标。

## 单岗位核验交付

单岗位查询默认输出一页式“岗位核验卡”，不必生成完整城市报告。卡片至少包含：企业/招聘主体、完整岗位名、岗位编号或匹配置信度、工作地点、原始来源、最后核验时间、岗位开放状态、届别/学历/专业匹配、广告薪资原文与年化口径、双休/轮班、出差/驻场/现场实施、住宿/班车、证据等级、空缺项和 HR 书面核验问题。

岗位状态写“原始页明确开放、原始页明确关闭、页面不可用但无法判断是否停招、仅见转载/摘要”之一，不能用“搜索还能搜到”代替开放状态。单岗位条件未知时写“未确认”，同时给出保守现金压力测试；不为一个岗位制造薪资分位数或企业集中度。

## 最终验收清单

### 数据与计算

- 每个城市/区县都有数据截止日、来源键和证据等级；
- 招聘薪资、官方工资、广告薪资、到手现金的标签没有混用；
- 整租/合租、直租/中介、现金/公积金可以分别复算；
- 押金、预付、中介费、服务费、水电气网分别计入正确位置；
- 负数、空值和“未知”没有被静默当成 0；
- 同一职位没有重复计数，样本企业集中度已显示；
- 任何小于预设样本量的城市/区县都降级或标“仅观察”；
- 默认参数在报告、Excel 和 HTML 中一致。

### 文档与交互

- Word 表格没有跨页截断、重复表头丢失或错位；
- Excel 无断链、无 `#REF!`、无整列误算，抽样单元格可复算；
- HTML 离线打开、输入边界值不报错、标题和单位随情景更新；
- 图表和正文引用同一版数字；
- 关键结论都有一句“本结论何时不成立”；
- 限制部分列出所有未覆盖地区、数据源失败和小样本项。

### 交付命名

建议使用日期和情景后缀，例如：

```text
2027届_<专业>_<地区>_城市净结余报告_YYYY-MM-DD.docx
2027届_<专业>_<地区>_数据总表_YYYY-MM-DD.xlsx
2027届_<专业>_<地区>_参数化测算_YYYY-MM-DD.html
```

同一项目的 Word、Excel 和 HTML 使用同一 `config.json` 与同一天的数据截止日。若只重跑一个交付物而其他文件未同步，不能把它们称为同一版本。

## 可复用但不机械化的边界

字段和脚本可以复用，来源、政策、租期、岗位族和样本必须按地区重查。更换地区时至少重新确认：社保/公积金基数与比例、租房常见押付和中介规则、目标岗位关键词、城市/区县映射、当地最低工资和落户/补贴政策。不要因为上一地区的“最优区县”或“默认比例”而跳过新地区的核验。
